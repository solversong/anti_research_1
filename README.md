# 항생제 임상규칙 실험

연세대학교 일반대학원 인공지능학과 송인성의 졸업연구용 실행 코드입니다. 지도교수는 김선주 교수입니다. 문헌 기반 24개 규칙은 **연구자·AI 초안이며 전문의 미검수** 상태입니다. 이 저장소의 실행기는 검수 전 파일럿입니다. 정식 임상 참조기준을 갖춘 평가나 진료용 도구가 아닙니다.

## 시작과 상태 확인

Mac Studio의 `Antibiotic_Research` 폴더에서 **임상규칙_실험_시작.command**를 열면 메뉴가 나옵니다. 합성 2건, 합성 24건 또는 모델 호출 없는 사전검사를 선택합니다. **임상규칙_진행상태.command**는 별도 터미널에서 최신 실험을 계속 표시합니다. 상태 보기만으로 실험이나 서버가 시작되지는 않습니다.

실행 중 이번 단계의 완료/목표, 정상/실패, 현재 요청 경과시간, 전체 경과시간, 최근 생존 신호와 대략적인 남은 시간을 표시합니다. 생존 신호는 실행 프로세스가 동작한다는 뜻이며 모델이 정상적인 임상 판단을 하고 있다는 뜻은 아닙니다. 응답을 기다리는 동안에도 표시가 갱신됩니다. 모델 출력 형식 오류는 실패로 유지합니다.

Ctrl+C는 시작 창에서 실행 중단을 요청하고, 상태 창에서는 모니터만 닫습니다. 응답을 받기 전에 중단된 호출은 추론 완료 여부 미확정으로 기록합니다. 새 시도는 새 결과 폴더에 저장됩니다. 자동 재시도는 없습니다. 강제 종료나 시스템 종료로 생존 신호가 끊기면 모니터가 미확인 상태를 표시하며 완료로 바꾸지 않습니다.

## 코드 구성

| 파일 | 역할 |
|---|---|
| `run_draft_pilot.py` | 입력 검사, 로컬 모델 호출, 동일 C 응답에 D 적용, 결과·실행 이력 |
| `draft_gate.py` | 적용 범위·조건·예외를 검사하는 정적 규칙 엔진 |
| `clinical_rules_draft_v0.1.json` | 출처와 검수 질문을 포함한 24개 규칙 초안 |
| `prepare_pilot.py` | 입력 동결 도구; 실제자료 준비는 별도 명시적 작업 |
| `local_runtime.py` | 로컬 endpoint, 전체 모델 digest, tokenizer 해시 검사 |
| `progress.py`, `monitor.py` | 집계 전용 상태 기록과 터미널 모니터 |
| `launch.py` | 실행 메뉴, 중복 실행 잠금, 전용 로컬 서버 시작·정리 |
| `test_*.py` | 완전 가상 입력을 사용한 소프트웨어 검사 |

## 실행 환경과 명령

허용 호스트는 `Ericui-MacStudio.local`입니다. Python 3.10 이상, 이미 설치된 로컬 transformers/tokenizer, 연구 전용 Ollama와 digest가 고정된 qwen3.5:27b가 필요합니다. 시작 버튼은 기존 연구 전용 Python 환경을 재사용합니다. 저장소를 받았다는 이유만으로 패키지나 모델을 자동 설치하지 않습니다. 모델이나 지침 변경은 새로운 동결 입력과 버전으로 수행합니다.

```sh
python3 -m unittest discover -v
python3 monitor.py --root /절대경로/outputs/clinical_rules_runs --once
python3 monitor.py --root /절대경로/outputs/clinical_rules_runs --follow
python3 launch.py --research-root /절대경로/Antibiotic_Research --dry-run
python3 launch.py --research-root /절대경로/Antibiotic_Research --limit 2
```

모델을 사용하는 명령은 프로젝트 전용 Python으로 실행해야 합니다. 마지막 두 명령은 기존 동결 입력의 위치와 해시를 확인합니다. 실행 버튼은 실제 환자 입력을 자동 실행하지 않습니다. 저수준 실행기의 실제 보정자료 모드는 별도의 명시적 연구 작업에 사용하며 미노출 시험자료를 개발에 사용하지 않습니다. 기존 동결 입력은 이 저장소에 포함하지 않습니다.

## 결과와 재현성

새 실행은 연구 폴더의 `outputs/clinical_rules_runs/날짜-식별값/`에 저장됩니다. `progress.json`은 현재 집계, `events.jsonl`은 집계 이벤트, `run_manifest.json`은 최종 실행 계약입니다. 호출 기록에는 민감한 내용이 포함될 수 있으므로 로컬에만 둡니다. 원문 파일을 터미널에서 tail하는 방식으로 모니터링하지 않습니다.

실행 계약은 코드 SHA-256과 Git commit/작업 트리 상태를 기록합니다. 커밋하지 않은 코드로 실행했다면 그 사실을 남깁니다. 코드나 입력이 다르면 과거 prefix를 이어 실행할 수 없습니다. 이전 2026-10-05 파일럿 26회는 원래 폴더에 보존되어 있고 이 코드의 검사·데모 호출 수에 합산하지 않습니다. 테스트의 가짜 transport는 모니터 소프트웨어 검증일 뿐 실제 모델 실험이 아닙니다.

C는 규칙을 받은 단일 모델, D는 **저장된 동일 C 출력**에 조건 검사를 적용합니다. D 추가 모델 호출은 없습니다. 합성 명세 일치와 임상 정확도를 구분하며 전문가 참조기준 없이 임상 우위·안전성을 계산하지 않습니다. 연구계획서 v1.4의 주 비교를 바꾸지 않습니다.

## Git 범위

소스·문헌 규칙·가상 테스트·사용법만 버전 관리합니다. 환자자료, 협진 원문, 입력팩, 프롬프트, 모델 응답, 결과물, 로그, API 키, tokenizer, 가중치, 가상환경은 저장소에 포함하지 않습니다. `.gitignore`는 기본 제외 방식이며 `TRACKED_FILES.json`의 명시 목록과 커밋 전 검사로 관리합니다. `git add -f`로 이 제외를 우회하지 마십시오.

원본 코드 출처·해시는 `PROVENANCE.json`에 있습니다. 변경 후 가상 테스트를 통과시키고 `python3 repo_guard.py`로 Git 파일 목록을 검사한 뒤 커밋합니다. 훅 설정은 이 저장소에만 적용합니다: `git config core.hooksPath .githooks`. 다른 컴퓨터에서 임상 실험을 실행할 권한을 부여하는 저장소가 아닙니다.
